DESIGN EXECUTION TASKS

1) Typography: Set all text with proper tracking, leading, and kerning. No overlapping characters.
2) Grid alignment: All elements snap to the underlying grid. Prices align in a clean column.
3) Visual hierarchy: Title > Section headers > Item names > Descriptions/Prices
4) Whitespace: Generous breathing room around text blocks. No crowding.
5) Consistency: All similar elements (sections, items, dividers) styled identically.
6) Balance: Visual weight distributed evenly across the page.
